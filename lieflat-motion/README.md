# Lieflat Charts 深度研究三部曲

30 秒、1920×1080、30fps 的 Remotion 动画，对应仓库里的三册研究报告。

主合成 id：`LieflatTrilogy`。七场可以在 Studio 的 Scenes 文件夹里单独打开。

```console
npm i
npm run dev
```

Studio 地址：<http://localhost:3000/LieflatTrilogy>

导出 MP4：

```console
npx remotion render LieflatTrilogy out/lieflat-trilogy.mp4
```
